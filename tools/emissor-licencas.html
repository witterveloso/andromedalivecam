Emissor de Licenças · Andrômeda Live

Para o vendedor. Funciona sem internet: nada sai deste computador.

1Criar as chaves (só uma vez)

Cria o par de chaves da sua empresa. A chave privada emite as licenças e fica só com você. A chave pública vai dentro do programa para conferir as licenças.

Guarde o arquivo licenca-privada.pem em lugar seguro, com cópia de segurança (pendrive, cofre de senhas). Sem ele, você não emite mais licenças; com ele, qualquer pessoa emitiria. Nunca envie a chave privada para ninguém, nem para o GitHub ou um chat.

2Emitir uma licença

O cliente vê o código do computador na mesa: Diagnóstico → Licença. Cada licença vale só para aquele computador.

Renovar e cancelar

Renovar: emita uma licença nova para o mesmo código do computador e envie ao cliente. A anterior continua valendo até vencer.
Vencimento: depois do vencimento o cliente tem 3 dias de tolerância. Sem renovação, a transmissão fica bloqueada até ele colar uma licença nova.
Troca de computador: peça o código do computador novo e emita para ele.
